SQL

joins · aggregation · CTEs · window functions · tuning

Short, dense and unapologetically practical. This is the course you take if the job description says "strong SQL" and you are not sure you qualify.

6 weeks Beginner Fastest track
  • Read and rewrite queries you inherit from someone else.
  • Solve window-function problems without a subquery habit.
  • Debug slow queries and read an execution plan.
  • Handle live SQL interview rounds with a plan.
View syllabus
  1. Relational basics - SELECT, filtering, sorting
  2. Joins and set operations
  3. Aggregation, GROUP BY and HAVING
  4. Subqueries and common table expressions
  5. Window functions - ranking, running totals, gaps
  6. Query tuning and interview practice
